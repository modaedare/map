# نقشه مدارس ملارد معاونت پرورشی و تربیت بدنی

نقشه تعاملی مدارس شهرستان ملارد با نقشه پایه Esri، نشانگر مستقل برای هر مدرسه،
جست‌وجوی نام و نشانی، و فیلتر مقطع، جنسیت و دولتی/غیردولتی.

فونت رابط کاربری: Vazir (بارگذاری از CDN).

## انتشار با GitHub Pages
فایل‌های این پوشه را در ریشه مخزن GitHub قرار دهید و از Settings → Pages انتشار را فعال کنید.
