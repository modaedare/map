# نقشه تعاملی مدارس شهرستان ملارد

این پروژه یک وب‌سایت ایستا (Static) و مناسب انتشار رایگان روی GitHub Pages است.

## انتشار با GitHub Pages

1. در GitHub یک مخزن جدید با نام `malard-schools-map` بسازید.
2. فایل‌ها و پوشه‌های داخل این پروژه را در ریشه مخزن بارگذاری کنید؛ فایل `index.html` باید در ریشه باشد.
3. از بخش **Settings → Pages**، گزینه **GitHub Actions** را به‌عنوان Build and deployment انتخاب کنید.
4. با هر بار push به شاخه `main`، گردش‌کار موجود در `.github/workflows/pages.yml` سایت را منتشر می‌کند.
5. نشانی سایت معمولاً به شکل `https://USERNAME.github.io/malard-schools-map/` خواهد بود.

## نقشه پایه

برای جلوگیری از خطای 403 سرویس کاشی عمومی OpenStreetMap، نقشه پایه پیش‌فرض به CARTO Voyager تغییر داده شده و یک لایه جایگزین Esri نیز در کنترل لایه‌ها قرار دارد. این سرویس‌ها برای نمایش نقشه به اینترنت نیاز دارند.

## نکته داده‌ها

نقشه فقط رکوردهایی را نمایش می‌دهد که مختصات آن‌ها در محدوده جغرافیایی انتخاب‌شده برای ملارد قرار گرفته است. مختصات ناقص یا مشکوک در نسخه اکسل جداگانه مشخص شده‌اند. پیش از انتشار عمومی، توجه کنید که این داده‌ها شامل نشانی و شماره تماس بعضی مدارس هستند؛ انتشار عمومی آن‌ها باید با مجوز و ملاحظات حریم خصوصی اداره انجام شود.
