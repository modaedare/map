# نقشه مدارس ملارد معاونت پرورشی و تربیت بدنی

سایت ایستا برای انتشار با GitHub Pages.

## انتشار
1. فایل‌های این پوشه را در ریشه مخزن GitHub بارگذاری کنید.
2. در Settings → Pages، منبع انتشار را روی GitHub Actions قرار دهید.
3. گردش‌کار موجود در `.github/workflows/pages.yml` سایت را منتشر می‌کند.

نقشه پایه فقط از سرویس Esri استفاده می‌کند. همه مدارس با نشانگر مستقل نمایش داده می‌شوند و خوشه‌بندی عددی غیرفعال است.
جست‌وجوی نام و نشانی و فیلتر مقطع و جنسیت فعال است.
